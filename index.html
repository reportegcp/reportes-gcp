¿Cómo se determina el período?

El sistema usa el Inicio ejercicio de cada Obra Social para saber qué Cartilla debe buscar.

Ejemplo: para el período de control 2026, una OS con inicio 01-01 busca ejercicio 2026; si inicia en otra fecha, busca 2025/26.
